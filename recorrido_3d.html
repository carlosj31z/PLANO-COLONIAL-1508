Cómo usar el modelo

Vista 3D
Arrastra para girar, rueda o pellizco para acercar, clic derecho o dos dedos para desplazar.
Planta
Vista desde arriba, igual que el plano. Arrastra el fondo para desplazarte.
Muebles
Toca un mueble para seleccionarlo y arrástralo para moverlo. Flechas: mover 5 cm (Mayús: 25 cm). R: girar 90°. Supr: eliminar. Agrega más desde la ficha Muebles.
Recorrido
WASD o flechas para caminar, ratón para mirar (clic en la vista para capturarlo, Esc para soltarlo), Mayús para ir más rápido, E o clic para abrir y cerrar puertas. En el celular usa el círculo para caminar y arrastra la pantalla para mirar.
Acabados
Cambia pisos, papel mural, pintura, granito y carpintería por ambiente. Los valores iniciales siguen el anexo de acabados.

Tus cambios se guardan en este navegador. Para llevarlos a otro equipo usa «Copiar diseño» en la ficha Vista. La geometría es aproximada: el plano del anexo no trae cotas y la escala se dedujo del área techada (72.82 m²).
